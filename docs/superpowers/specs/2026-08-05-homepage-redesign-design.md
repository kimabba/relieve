# 홈페이지 리디자인 설계 (2026-08-05)

## 배경

기존 홈페이지(`src/app/[locale]/page.tsx`)는 Waxly 테마로 리디자인된 상태지만, 디자인·브랜드 이미지가 낡았다는 판단으로 처음부터 다시 기획한다.

## 목적 (핵심 결정 사항)

- **주 목적**: 정보 전환(예약 유도)이 아니라 **쇼케이스/포트폴리오**. 실질 리드는 네이버 광고·플레이스가 담당하며, 이 홈페이지는 검색으로 우연히 들어오는 손님과 타업체에게 "이 정도 퀄리티를 뽑아내는 곳"이라는 인상을 남기는 용도.
- **부 목적**: SEO를 통한 유입도 계속 유지 (최근 커밋 이력에 sitemap.xml, SEO 최적화 작업이 이어져 옴 — 이 흐름을 끊지 않는다).
- **핵심 포지셔닝**: "임산부 왁싱"이라는 인구통계 자체보다, **병원급 신뢰·청결**이 실제 차별점. 임산부 왁싱으로 유명하다는 것은 그 신뢰의 증거일 뿐 목적이 아니다.

## 화려함과 SEO/전환의 배치 원칙

3D/모션은 **Hero 섹션에만 집중**한다. 그 아래 정보 섹션(신뢰 요소, 예약 도선)은 가볍고 빠르게 유지해 SEO(Core Web Vitals)와 실제 예약 전환을 해치지 않는다. 페이지 전체에 3D를 두르는 방식(Awwwards 풀 인터랙티브형)은 로딩 속도가 SEO 목표와 정면 충돌하므로 채택하지 않는다.

## 신뢰 요소 (홈페이지에 반드시 노출)

사용자가 확정한 4가지:
1. 위생·멸균 관리 프로세스
2. 자격증·인증·경력
3. 임산부/민감성 피부 전용 응대 설명
4. 실제 후기·평점 (네이버 리뷰)

## Hero 기술 스펙

- **라이브러리**: `react-three-fiber` (신규 의존성 추가, 코드로 직접 제작 — Spline 임베드 대비 성능/용량 통제 우선)
- **씬**: 슈가링 페이스트를 형상화한 앰버/카라멜톤 유기적 3D 블롭. 마우스/스크롤 반응 변형. 실사 인물/제품 사진 대신 추상 오브젝트라 저작권·촬영 부담 없음
- **로딩 전략**: `next/dynamic`으로 지연 로드. 로딩 중에는 현재 Hero의 정적 크림톤 그라디언트를 플레이스홀더로 노출
- **모바일/저사양 폴백**: `prefers-reduced-motion` 및 디바이스 성능 감지 시 정적 이미지로 자동 대체
- **SEO 격리**: 3D 컴포넌트는 클라이언트 전용(`"use client"` + dynamic import)이라 서버사이드 렌더링되는 나머지 페이지 텍스트 인덱싱에 영향 없음

## 성능/SEO 안전장치

- Core Web Vitals 예산: LCP 2.5초 이내
- 3D는 Hero에만 격리, 그 외 섹션은 순수 정적 렌더링 유지
- 기존 `next.config` 이미지 도메인 화이트리스트, 기존 SEO(sitemap, metadata) 작업 유지

- **재작성**: `src/components/home/Hero.tsx` (3D 씬 추가)

- **콘텐츠만 교체**: `ReviewHighlights.tsx` (임산부 후기 3건 반영)

## 범위 밖 (이번 설계에서 다루지 않음)

- 서브페이지(`/services`, `/about`, `/reservation` 등)는 이번 리디자인 범위 아님 — 홈페이지(`/`)만 대상
- 다국어(`en`) 카피는 구조를 따라가되 문구 확정은 구현 단계에서 별도 처리
